# 📝 پروژه TODO App

یک اپلیکیشن مدیریت وظایف ساده و ریسپانسیو که با
HTML، CSS و JavaScript ساخته شده است.

در این پروژه کاربر می‌تواند وظایف خود را اضافه، حذف و تکمیل کند
و همچنین ترتیب وظایف را با Drag & Drop تغییر دهد.

## 💾 ذخیره اطلاعات

وظایف در `Local Storage` مرورگر ذخیره می‌شوند.

به همین دلیل با رفرش کردن صفحه، وظایف حذف نمی‌شوند.

البته اطلاعات فقط در مرورگر فعلی کاربر ذخیره می‌شوند.
